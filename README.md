# 🌷 يومي — منظمي الشخصي

منظم شخصي (Personal Organizer) بواجهة عربية RTL يجمع في مكان واحد: نية اليوم،
الصلاة، المهام، الدراسة، العادات، الأهداف، وأثر الخير اليومي — مبني حسب خريطة
التطبيق المرفقة في هذا المستودع.

## البنية

- **البداية / التعريف بالمستخدمة**: ترحيب، الاسم، الاهتمامات، اختيار 3–5 عادات،
  واختيار لون التطبيق (5 مظاهر پاستيل).
- **يومي** (الشاشة الرئيسية): نية اليوم، صلاتي (٥ صلوات)، أهم مهامي، عاداتي،
  وبطاقة "أثري اليوم"، بالإضافة لبطاقة مراجعة المساء تظهر تلقائيًا مساءً.
- **دراستي**: ملخص الأسبوع (مهام / اختبارات / جلسات مذاكرة) وموادي، وعند فتح
  مادة: مهامها واختباراتها وجلسات مذاكرتها.
- **أهدافي**: أهداف بخطوات وشريط تقدم.
- **عاداتي**: تتبع أسبوعي (٧ أيام) لكل عادة بدون رسائل "فشل" — تشجيع دائمًا.
- **أثري**: إضافة أثر سريع (وسوم جاهزة أو نص حر) وسجل "آثاري الجميلة"، ويمكن
  الوصول له من "يومي" ومن "مساحتي" (وليس تبويبًا مستقلًا في الشريط السفلي).
- **مساحتي**: الملف الشخصي — الاسم، اللون، اختصارات للعادات/الأهداف/الأثر،
  ملاحظاتي، وإعدادات التطبيق (بما فيها إعادة الضبط).

كل البيانات تُحفظ محليًا على الجهاز (`localStorage`) — لا حاجة لحساب أو اتصال
بالإنترنت.

## التقنيات

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- خط Tajawal (Google Fonts) لدعم عربي مريح

## التشغيل محليًا

```bash
npm install
npm run dev       # تشغيل بيئة التطوير
npm run build     # بناء نسخة الإنتاج
npm run lint      # فحص الكود
```

## النشر (رابط دائم مجاني عبر GitHub Pages)

المستودع يحتوي على `.github/workflows/deploy-pages.yml` يبني وينشر التطبيق
تلقائيًا على GitHub Pages مع كل push لفرع `claude/personal-organizer-app-map-y8rrdh`.

**خطوة واحدة فقط عليكِ فعلها يدويًا (لمرة واحدة):**

1. من صفحة المستودع على GitHub: **Settings ← Pages**.
2. تحت "Build and deployment" اختاري **Source: GitHub Actions** (إن لم تكن
   محددة تلقائيًا).
3. من تبويب **Actions**، تأكدي أن ورك‌فلو "Deploy to GitHub Pages" اشتغل
   بنجاح (أو شغّليه يدويًا عبر "Run workflow").

بعدها سيظهر الرابط الدائم في نفس صفحة Settings ← Pages، عادة بالشكل:
`https://<اسم-الحساب>.github.io/YOMI/`

هذا الرابط:
- **مجاني ودائم** ويتحدّث تلقائيًا مع كل تعديل تدفعينه للفرع.
- **لا يحتاج أي حساب أو تسجيل دخول** لأي طالبة — تفتحه من المتصفح مباشرة.
- بيانات كل طالبة (نيتها، مهامها، عاداتها، أثرها...) تُحفظ في متصفحها هي فقط
  ولا تُشارك مع أحد.
- قابل للتثبيت كأيقونة حقيقية على الشاشة الرئيسية (Add to Home Screen) بفضل
  ملف الـ Web App Manifest المرفق — يظهر باسم "يومي" وأيقونة الزهرة 🌷.
